# Almalinux 10 for WSL and Windows 11 - Bulid amazing desktops via Almalinux 10

Almalinux - Windows Subsystem for Linux is designed as an integration between Windows and Linux. You can run the AlmaLinux terminal environment on a Windows machine. Supported AlmaLinux OS versions. Almalinux works well on desktops via WSL. AlmaLinux is an Enterprise Linux distro, binary compatible with RHEL, and guided and built by the community.
